# 表达训练器 · Expression Trainer

面向中文表达训练的 AI 产品原型：把一份资料拆成两轮“阅读—转述—反馈”练习，帮助用户减少口头习惯、提炼中心信息，并用可追溯证据复盘表达质量。

> 当前版本聚焦可验证的 Web 与 Android 体验。它不会把“自动化测试通过”包装成真人、真机或生产环境验收。

## 产品亮点

- **两轮训练闭环**：同一知识包生成不同但可追溯的练习，分别训练完整表达与快速总结。
- **语音证据优先**：区分真实时间戳、缺失录音证据和低置信识别，不伪造停顿数据。
- **规则 + 模型协作**：本地规则负责稳定评分，用户可通过 BYOK 接入 OpenAI、DeepSeek、Claude 或 Gemini 做语义补强。
- **隐私边界明确**：公开版默认 BYOK；模型密钥仅保存在服务端内存，并设有过期和主动断开机制。
- **多端交付**：包含浏览器前端、Python 服务、Android WebView/原生 PCM 录音桥接与通用容器部署模板。
- **可运营但不过度采集**：匿名访客隔离、训练记录、个人汇总、数据删除和可选分析均有独立契约。

## 体验路径

1. 选择内置题目或导入自己的资料。
2. 完成第一轮阅读与转述，查看证据、评分和聚焦建议。
3. 在同一知识范围内完成第二轮快速总结。
4. 对照两轮结果，查看训练计划与成长记录。

## 快速启动

仅预览静态界面：

```bash
npm install
npm run web
```

运行包含训练记录、BYOK 和语音任务接口的本地服务：

```bash
npm install
npm run web:p0:core
```

随后访问 `http://127.0.0.1:4173/`。可复制 `.env.example` 配置可选能力；请勿提交真实密钥。

## 验证

```bash
npm run check:secrets
npm test
```

当前公开基线包含 70 项前端测试与 64 项后端测试，覆盖训练评分、录音状态、身份隔离、模型连接、预算限制、隐私与部署边界。生产依赖经 `npm audit --omit=dev` 检查为 0 个已知漏洞。

## 技术架构

```text
Browser / Android
  ├─ 训练流程、草稿恢复、录音与结果呈现
  ├─ Web Speech 或 Android 原生 PCM
  └─ 只持有短期、不可反查的连接标识
                 │
                 ▼
Python service
  ├─ 用户隔离、训练记录与统计
  ├─ 分块音频任务与转录适配
  ├─ 规则评分与语义证据归一化
  └─ BYOK / 受限内测模式的访问控制
                 │
                 ▼
Optional providers
  ├─ OpenAI / DeepSeek / Claude / Gemini
  └─ FunASR / 火山语音
```

## 已知边界

- 公开仓库不含任何模型密钥、运营口令、用户数据、签名文件或本机验收截图。
- 模型与语音供应商能力需要使用者自行配置；未配置时相关功能会明确失败，不回退成伪造结果。
- 自动化覆盖不等于所有 Android 厂商真机、浏览器麦克风权限或生产部署已经验收。
