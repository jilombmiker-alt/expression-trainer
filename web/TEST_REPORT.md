## 仍需真人验证

- 原桌面版离线 ASR 当前不可验收：源码要求的 Paraformer 模型未包含在压缩包中，`models/` 只有 `.gitkeep`。
- 点击「检查并开启麦克风」后的系统权限弹窗与真实音量：自动验收没有替用户接受麦克风权限，也无法实际说中文。
- macOS / Windows 上 Chrome、Edge、Safari 的拒绝后恢复路径。
- 不同口音、噪声环境和连续 1–3 分钟表达的识别准确率。
- 当前 Web Speech 只是浏览器基线；高精度中文 ASR 需要独立服务或补齐离线模型后进行同一音频集对比评测。
- 本轮只在 1280px 宽屏做了真实截图验收；窄屏已有 CSS 断点，但仍需手机或可控窄屏浏览器进行截图与触控验收。
