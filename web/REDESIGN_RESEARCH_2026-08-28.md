## 四个方向

1. 纸上声场：温暖编辑感，适合成熟、可信、陪伴型品牌。
2. 像素脉冲：数字实验室，适合年轻、强记忆点和即时反馈。
3. 语义流光：沉浸式 AI 语音感，适合品牌展示和科技叙事。
4. 清晰工作台：SaaS 产品化表达，适合优先验证易懂性和转化。

## 产品层面的共同修正

- 进入页面就能填示例和生成本地报告，不把 API Key 当作第一道门槛。
- 麦克风只有点击后才请求；拒绝权限后仍可完成文字分析。
- 识别“先说结论、第一点、第二点、第三点、举例、总结”等逻辑标记。
- 先允许用户修改识别稿，再分析；清理稿只去冗余，不增加用户观点。
