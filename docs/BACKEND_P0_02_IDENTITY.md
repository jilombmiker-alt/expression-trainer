# 后端 P0 · 阶段 02：访客隔离与密钥边界

日期：2026-09-04。状态：单机访客隔离基础已实现，不是正式登录系统。

## 会话

打开 HTML 页面或 `GET /api/session` 创建/恢复访客。随机会话令牌保存在 `HttpOnly; SameSite=Strict` Cookie，默认 30 天；数据库只存令牌 SHA-256 与内部访客编号。常规 API 不会给无会话请求自动分配权限。

生产 HTTPS 环境必须设置 `EXPRESSION_SECURE_COOKIE=true`。当前服务默认仅监听本地回环，未改变为公网监听。

## 数据权限

模型连接、录音任务在创建时绑定访客。查询、模型测试、提交/上传音频、取消、删除、语义调用均核对归属；其他访客及无归属的旧资源返回 404。训练和作答使用内部 owner 字段查询。客户端不能指定 owner。

旧连接不自动认领；升级后需重新接入模型。旧录音数据未被删除，但没有可靠所有权记录的任务不能通过新 API 直接访问。旧浏览器草稿不是服务器成绩凭证。

## 密钥与日志

- Key 仍只驻留模型连接进程内存，原有 TTL 和撤销行为保留；不写入 SQLite。
- HTTP 日志仅输出事件、方法、状态，不输出原始路径、查询串、Cookie 和请求头。
- 模型连接 ID 及语音热词可能出现在 URL，因此不保留原始访问日志。
- 浏览器跨站来源被拒绝；合法同源请求和带 Cookie 的本地诊断请求可用。

## 数据位置和恢复

默认 `.p0-data/training.sqlite3`；可通过 `EXPRESSION_DATA_DIR` 配置整个数据根目录。SQLite 使用事务、WAL 和独立连接。重启保留训练记录；BYOK 内存连接重启后失效，需要重填。`.p0-data/` 已被 Git 忽略。

## 验收

两个不同 Cookie 的 HTTP 集成测试覆盖模型查询/删除、录音查询/取消和训练结果隔离；另测令牌哈希、持久化、过期、跨站拒绝和日志脱敏。

## 上线前缺口

正式账号及找回、跨设备迁移、退出/注销/删除个人资料、资料和音频保存期限、持久化数据加密、备份恢复演练、共享存储、多实例、HTTPS、全站限流与资源配额尚未完成。Cookie 删除或过期后没有账号找回途径。目前只适合本地验收，不能据此宣称已具备公网多用户生产安全。
