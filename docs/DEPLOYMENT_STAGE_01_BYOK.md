# 上线阶段 01：BYOK 多模型接入

## 1. 本阶段对应手册的哪一步

《AI Agent 产品上线部署手册》在前端完成后的下一步，是“上线前代码改造”，重点包括登录与数据隔离、数据持久化、文件存储、密钥管理和监控。本阶段先完成其中的模型密钥边界：公开产品默认不使用产品方 API Key，而由使用者接入自己的模型。

这一步不等于产品已经完成正式部署。账号体系、数据库持久化、对象存储、HTTPS、日志脱敏和线上监控仍属于后续部署阶段。

## 2. 产品目标

- 用户可选择 OpenAI、DeepSeek、Anthropic Claude、Google Gemini。
- 用户自行填写其账户中实际可用的模型名称和 API Key。
- AI 语义评分消耗用户自己的模型额度，不消耗产品方额度。
- 未接入 BYOK 时，浏览器训练仍可运行本地规则分析，但后端拒绝调用产品方模型。
- API Key 不进入仓库、静态网页、`localStorage`、`sessionStorage`、接口响应和业务日志。

## 3. 数据流

1. 浏览器把厂商、模型名和 API Key 通过同源 HTTPS 请求发送给后端。
2. 后端验证厂商白名单、模型名称格式和密钥格式。
3. 后端只在进程内存中保存密钥，默认 8 小时失效，并返回不可猜测的连接编号。
4. 浏览器只把连接编号写入 `sessionStorage`。
5. 训练发起语义分析时，浏览器通过 `X-Model-Connection` 请求头传递连接编号。
6. 后端取出对应密钥并直接调用所选厂商；结果通过既有语义证据校验后才用于评分。

## 4. 安全取舍

### 已完成

- 固定厂商白名单和固定官方 API 域名，不允许用户填写任意 Base URL，避免 SSRF。
- API Key 仅存于服务端内存；服务重启、连接过期或用户断开后立即失效。
- 页面用密码框输入密钥，只在用户主动点击时临时显示。
- 接口只返回掩码密钥，永不返回原密钥。
- 默认 `EXPRESSION_REQUIRE_BYOK=true`，没有用户连接时不会退回产品方 Key。
- 连接测试会真实调用一次用户所选模型，并明确提示可能产生极少量费用。

### 正式上线前仍需完成

- 全站 HTTPS；没有 HTTPS 时不得开放 BYOK。
- 登录后把连接编号绑定到当前用户和当前会话，不能只依赖随机编号。
- 多实例部署时使用带 TTL 的加密临时存储或云密钥托管；当前内存存储不跨实例。
- 接入请求限流、异常告警、供应商调用审计和完整日志脱敏。
- 增加用户协议、隐私说明和“删除密钥”说明。

## 5. 后端接口

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| `GET` | `/api/model-connections/providers` | 读取允许接入的厂商 |
| `POST` | `/api/model-connections` | 创建临时连接 |
| `GET` | `/api/model-connections/{id}` | 读取不含密钥的连接状态 |
| `POST` | `/api/model-connections/{id}/test` | 最小真实模型测试 |
| `DELETE` | `/api/model-connections/{id}` | 立即断开并删除内存密钥 |
| `POST` | `/api/semantic/evaluate` | 使用 `X-Model-Connection` 调用用户模型 |

## 6. 配置

```text
EXPRESSION_REQUIRE_BYOK=true
EXPRESSION_BYOK_TTL_SECONDS=28800
EXPRESSION_LLM_TIMEOUT_SECONDS=30
EXPRESSION_LLM_RETRIES=1
```

只有受控的内部部署才应把 `EXPRESSION_REQUIRE_BYOK` 改为 `false` 并配置产品方备用模型。

## 7. 验收结果

- 四种厂商请求格式均有自动化测试。
- 未知厂商和危险模型路径被拒绝。
- 密钥不会出现在创建响应或模型请求正文中。
- 连接支持过期和主动撤销。
- 语义请求只携带不透明连接编号，不携带 Authorization 或 API Key。
- 全量自动化基线：58 项前端测试、21 项后端测试。

## 8. 入口与导航修订

- 模型接入不是独立产品落地页，而是“设置”中的一个项目。
- 知识创建页与训练页都把“设置”固定放在右下角底栏。
- 用户未接入模型就点击开始时，系统先保存所选训练内容，再跳转到 `settings.html?section=model&required=1`。
- 接入成功后显示“继续刚才的训练”，返回原内容并自动进入第一轮，不要求用户重新选题。
- 设置页直接复用知识训练页的 `app-shell`、页头、步骤导航、工作台、按钮、主题变量和底栏，V0 与 Programa 两种主题保持一致。

真实厂商可用性仍需用户提供自己的有效 Key 后逐厂商做一次冒烟测试；自动化测试不冒充真实模型验证。
