# 第 2 阶段前端开发技术文档｜第一条真实业务闭环

> 状态：已完成自动化与浏览器闭环；真人语音不在本阶段伪造。

## 1. 本阶段目标

用户能够从知识资料入口生成真实训练卡，进入同一知识包的训练页并看到可开始的第一轮，不依赖 Mock 页面证明闭环。

## 2. 范围

### 包含

- 知识示例填充、真实 `POST /api/training/from-source`、训练卡预览和进入训练。
- 训练页读取导入卡、确认内容并进入第一轮阅读。
- 提交加载、防重复点击、失败保留输入和本地规则降级边界。
- 桌面 1280px 与手机 390px 自动浏览器检查。

### 不包含

- 不用静默 Mock 替代知识接口。
- 不自动点击真实麦克风或采集用户环境声音。
- 不跳过 2–5 分钟和 30 秒的产品计时规则来伪造完整训练成绩。

## 3. 用户流程

1. 打开知识训练页并点击“使用示例”。
2. 点击“生成两轮训练”，按钮进入提交状态。
3. 后端返回来源约束的两轮训练卡，用户先预览。
4. 点击“进入表达训练”，同一训练卡写入当前会话。
5. 点击“开始”，进入第一轮阅读计时入口。

## 4. 页面状态矩阵

| 模块 | 初始 | 提交 | 成功 | 失败 | 恢复 |
|---|---|---|---|---|---|
| 知识表单 | 可输入/使用示例 | 禁止重复提交并显示整理中 | 展示两轮预览与来源 | 保留原输入并给出原因 | 可修改后重试 |
| 训练卡预览 | 未生成 | 等待接口 | 两轮可切换 | 不显示空白假结果 | 返回表单 |
| 训练选择 | 读取导入卡 | 不适用 | 确认后进入阅读 | 损坏卡安全回退 | 草稿入口仍保留 |

## 5. 接口与事实来源

- 真实接口：`POST /api/training/from-source`。
- 成功必须来自后端返回并通过训练卡校验。
- 服务超时或不可用时可以使用浏览器规则生成，但页面明确写明降级来源。
- `sessionStorage` 只保存尚未完成的训练卡，不冒充后端任务结果。

## 6. 实现结果

- 集中请求层处理超时与统一错误。
- `runOnce` 防止相同知识生成操作并发创建。
- 必填主题、至少 220 字资料在提交前验证；错误与字段关联并聚焦首个无效输入。
- 增加 SVG 站点图标，清除真实浏览器中的资源 404。

## 7. 验收结果

- 无痕 Chrome 真实启动 Python P0 服务并完成“示例 → 生成 → 预览 → 进入训练 → 开始第一轮”。
- 1280×800：页面根节点无横向和纵向滚动，Console 无错误。
- 390×844：页面根节点无横向和纵向滚动，生成按钮可触达。
- E2E 命令：`npm run test:e2e`，结果通过。

## 8. 风险与边界

- 知识服务当前是来源约束规则，不是大模型语义改写。
- 页面进入了第一轮真实入口，但没有用缩短计时或伪造文本产生虚假训练成绩。
- 真人语音与真实模型闭环继续进入后续人工验收。
