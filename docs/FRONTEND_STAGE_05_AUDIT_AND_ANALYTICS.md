# 第 5 阶段｜双手册复核、界面补强与埋点统计后端

## 技术适配声明补充

依据本轮提供的通用手册 V2.1（775 行）和前端手册 V1.0（1300 行）全文，以及既有 PRD、前端适配声明和上一批后端文档。

采用纵向切片：核验现有训练/设置界面 → 修复可访问性、移动布局、错误恢复 → 接入真实 SQLite 事件统计 → 浏览器查看真实空数据/汇总 → 自动化与截图验收。

保留现有原生 HTML/CSS、Python 同源服务和 `/api` 契约；不因为手册默认 Next.js/FastAPI 而整体重写。现有运行环境为 Python 3.9.6、Node 24.19.0，延续可运行环境，不擅自升级。新统计 API 适配模块使用 TypeScript strict + 运行时校验，旧千行页面的全量类型迁移仍属技术债。

## 本阶段范围

- 检查 390/768/1280/1440 宽度，重点覆盖训练、计划、成长与设置，不只检查首页。
- 修复小字体/小触控区域、移动端隐藏主要功能、弹窗焦点逃逸等有证据的问题。
- 后端新增个人汇总接口和独立管理员授权的全站汇总接口；不对普通用户泄露他人数据。
- 汇总以服务器训练/作答记录为准，客户端埋点仅作辅助，不生成假趋势、假活跃人数。
- 扩展已有设置页的数据入口，复用现有黑白视觉，不新增营销页或大面积装饰。

## 安全边界

不新增付费平台，不向第三方分析平台上传数据，不部署公网，不读取 Key 内容。运营权限独立于模型 Key 和访客身份；管理员凭证未配置时拒绝全站查询。默认个人数据只按当前访客隔离查询。统计响应不含正文、音频、Key 或用户身份列表。

## 验收计划

- API：空库、个人隔离、管理员拒绝/授权、去重、两轮分母、失败/恢复、未知 Token、时间窗。
- UI：真实后端统计加载/空/成功/失败、键盘、弹窗、响应式；截图确认，不以构建代替浏览器检查。
- 自动检查：lint、strict typecheck、前后端测试、build。
- 真实模型/麦克风/iPhone 验收仍待用户在设置填 Key 并实际录音，不冒充通过。

## 尚不包含

正式账号、完整云端等级/考试迁移、生产部署、外部告警、复杂 BI、多租户企业系统。指标与访问规则将在验收文档中逐条列明。

## 复核结论

原页面不是“按两本手册全部完成”的状态。单屏壳和主题已有基础，但移动端通过压缩字体、隐藏模块维持不滚动，造成实际功能不可达；已有埋点库也不等于可用统计后端。本阶段补齐重点缺口，不把模板的默认技术栈当作必须重写的指令。

| 手册关注项 | 复核发现 | 本轮处理 / 状态 |
| --- | --- | --- |
| 单屏、可操作、多屏宽 | 手机录音/转录与计划区挤成窄列，保持维度等直接隐藏 | 改成当前步骤内“查看”菜单；不卸载内容，不丢输入；保留页头页脚和步骤导航 |
| 全流程一致性 | 不只首页，教练重说、内容评分、七项评分、速记框架也被隐藏 | 评分页原有页签 + 内容菜单；恢复七项评分和教练/内容/趋势/结果入口 |
| 可读性与触控 | 基线存在 6–10px 文字，2–16 个不足 44px 控件 | 正文/输入提升；主要按钮 44px；补齐辅助说明与焦点样式 |
| 键盘和弹窗 | 麦克风校准只有 Escape，没有焦点约束 | Tab 循环、背景 inert、Escape 关闭与触发点焦点恢复；未申请真人录音权限 |
| 数据真实性 | 前端本地计划/考试文案像已认证 AI 能力 | 明确“按训练结果推荐”“本地模拟”；当前考试仍是本地规则，不冒充服务器认证 |
| 统一 API 与类型 | 旧页面仍大量 JS | 新布局及统计模块采用 TypeScript strict；统计响应有运行时校验；旧页面全面迁移未完成 |
| 正常/空/失败/授权 | 只有埋点写入，无真实个人统计 | 设置 → 数据与隐私；空数据无假分数；加载、错误重试、同意开关和服务端隔离 |
| 不可信内容 | 部分原文/模型证据/清理稿直接插入 HTML | 相关渲染点增加 HTML 转义；前端不是数据安全权限边界，后端仍验证归属 |
| 敏感数据保护 | 行为采集默认启动 | 可选行为采集默认关闭；正文与业务记录的保存边界在界面说明；管理员权限独立于 BYOK |
| 测试分层 | 过去构建/少量截图不足以证明训练全链路 | 单元/HTTP/Chrome 交互/真实统计分层验收；真实模型和真人录音仍单列待验 |

## 实现结构

- `web/quality-refinements.css`：沿用 V0 / Programa 已有颜色和组件，不引入新视觉主题；原生单屏壳不纵向增长。文章、转录、长表单只在自己的阅读/输入区域内滚动，功能切换走按钮或菜单。
- `frontend-src/quality-layout.ts`：面板保留 DOM，切换不销毁录音状态/文字；缩放回桌面自动恢复并列布局。
- `web/editorial.js`：校准焦点、内容转义、功能可达性和真实能力边界。
- `web/settings.html` + `frontend-src/analytics-settings.ts`：扩展现有设置页，不另起一套风格。
- 后端实现与完整指标口径见 `BACKEND_P0_05_ANALYTICS.md`。

## 视觉检查工具如何影响修改

UI/UX 检查推动修复 44px 操作区域和弹窗键盘焦点；Impeccable 检查推动移除设置页多余英文引题、放大功能性小字，保留现有用户确认的 Inter/PingFang 和黑白主题。检测器剩余的字体泛用、固定 viewport 裁剪告警经过人工判断：不为满足风格偏好擅自换用户主题；固定壳是既定产品要求，弹窗和步骤内容已另测。隐藏的旧英文节点仍可能被静态检测报引题，视觉输出已隐藏。

## 不应宣布两本手册整体结束

1. 真实模型 Key、中文真人转录、低置信确认、长录音、Safari/iPhone 真机仍需验收。
2. 旧 JS 页面尚未全面迁移严格类型及响应验证；此次新模块严格类型不能代表全站覆盖。
3. 正式账号与跨设备同步、云端计划/考试/成长认证、用户数据导出删除和保留期策略仍未闭环。
4. 模型分析仍是有界长请求，不是完整持久化语义任务队列；进程重启和未知付费结果的端到端恢复需继续强化。
5. 知识库生成目前为来源约束规则，未验证真实 OpenKB/RAG；模型评分仍需人工标注集校准，不能仅依靠阈值宣称能判定作弊。
6. 公网 HTTPS、正式管理身份、生产限流/容量、备份恢复、SLO/告警、负载验收、部署和 GitHub 发布不在本轮交付中。

本次结论：本地 P0 的前端易用性与埋点统计后端已补强；不是已上线、已完成生产安全验收的最终产品。
