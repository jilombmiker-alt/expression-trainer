# 第 4 阶段前端开发技术文档｜质量与发布准备

> 状态：本地工程质量门槛通过；正式发布仍需真人设备、真实模型和部署阶段。

## 1. 本阶段目标

在不改变已确认视觉方向的前提下，完成响应式、无障碍、性能、隐私、依赖安全和交付检查，让产品达到可进行正式设备验收的前端状态。

## 2. 范围

- 390px 手机与 1280px 桌面核心流程。
- 单屏页面、无横向滚动、受控内容区。
- 表单标签、字段错误、键盘焦点、跳转链接、对话框焦点和减少动态。
- 触控目标、SVG 图标、语义颜色变量和离线系统字体。
- Lint、TypeScript、单元测试、后端测试、E2E、静态构建与依赖审计。

## 3. 体验补强

- 移除运行时 Google Fonts 请求，改用系统中文字体回退，减少隐私和首屏网络依赖。
- 主题、危险和焦点颜色使用语义变量。
- 手机端文件、轮次切换和输入控件达到至少 44px 可触达高度。
- 知识表单错误使用 `role=alert`、`aria-describedby`、`aria-invalid` 并聚焦首个错误字段。
- 页面保留 skip link、可见 `:focus-visible` 和 `prefers-reduced-motion`。
- 麦克风校准弹窗已有 `role=dialog`、`aria-modal`、可访问关闭名称、焦点约束与 Escape 退出。

## 5. 浏览器结果

- 知识资料真实请求、预览、进入训练和第一轮入口通过。
- 1280×800 与 390×844 均无页面级横向/纵向溢出。
- 主操作在手机尺寸可见；Console 无持续错误或资源 404。
- 浏览器测试使用无痕上下文，不读取或删除用户现有训练数据。

## 6. 性能与隐私

- 不再运行时请求第三方字体。
- 当前页面无大型图片、图表和富文本编辑器，不引入额外懒加载框架。
- 轮询会在页面隐藏时降频；重复高成本提交受 single-flight 保护。
- 浏览器不包含模型 Key；用户资料作为纯文本渲染；错误不展示服务端堆栈。

## 7. 发布门槛与已知问题

以下项目完成前不能称为正式生产发布：

- HTTPS 正式域名、前后端生产部署和同源代理。
- 真人 Chrome/Safari/iPhone 麦克风与停顿校准。
- 真实语义模型 Key、同义/遗漏/冲突冒烟。
- 3/10 分钟真实录音与 FunASR 模型质量。
- 正式隐私政策、账号数据保存和删除策略。
- 375px、横屏、系统大字号和深色模式仍需真实设备专项检查；当前产品只确认浅色主题。
- 完整 `npm audit` 仍报告旧桌面版 Electron 33 / `extract-zip` 的 2 个高危开发依赖问题；修复要求破坏性升级到 Electron 44。当前 Web 产物不包含该运行时，生产依赖审计为 0；桌面版重新发布前必须单独升级并回归，不能直接运行 `npm audit fix --force`。

## 8. 回退与交接

- 静态构建输出在 `dist/`，源文件仍在 `web/`；删除生成产物即可重新构建，不影响用户本地训练数据。
- TypeScript 基础层输出为 `web/frontend-foundation.js`；源文件是 `frontend-src/frontend-foundation.ts`。
- 任何上线工作必须进入部署手册阶段，不沿用本地端口作为生产入口。

## 9. 本阶段结论

前端手册阶段 1–4 的本地工程工作已完成。产品已到“可进行真人设备和真实模型验收”的状态，而不是“已上线”。
